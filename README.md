# 🏹 The Rogue Archer

### A Retro Fantasy Archery Adventure

**The Rogue Archer** is a browser-based medieval fantasy game built using HTML, CSS, and JavaScript. Aim your bow, defeat enemy archers, collect rewards, and become the ultimate rogue archer!

## 🎮 Features

- **Interactive Gameplay:** Aim and shoot arrows using mouse controls.
- **Arrow Physics:** Arrows follow trajectories with velocity and gravity.
- **Enemy AI:** Enemies move, aim, and shoot back at the player.
- **Combat System:** Headshots instantly defeat enemies, while body hits reduce health.
- **Health & Pickups:** Collect health and arrows to survive longer.
- **Scoring & Rewards:** Earn points and coins by defeating enemies.
- **In-Game Shop:** Purchase extra arrows, badges, and avatars using coins.
- **Player Statistics:** Track scores, kills, shots, and shooting accuracy.
- **Game Controls:** Pause, resume, restart, and exit the game.
- **Progress Saving:** Uses browser LocalStorage to save supported game data.
- **Fantasy UI:** Features a dark medieval theme with crimson and golden accents.

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and responsive layouts
- **JavaScript** – Game logic and interactions
- **Canvas API** – Rendering characters, enemies, and arrows
- **LocalStorage** – Saving game progress in the browser
- **Git & GitHub** – Version control and project hosting
- **Vercel** – Deployment

## 🕹️ How to Play

1. Click **Play Game** to begin.
2. Move your mouse to aim your bow.
3. Hold the left mouse button and release it to shoot.
4. Aim for enemy heads to defeat them instantly.
5. Dodge incoming arrows and collect useful pickups.
6. Defeat enemies to earn points and coins.
7. Visit the shop to unlock available items.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Upandergarg/TheRougeArcher.git
   ```

2. Open the project in Visual Studio Code.
3. Navigate to the `FrontEnd` folder.
4. Open `index.html` using the Live Server extension.
5. Click **Play Game** and enjoy!

No framework or package installation is normally required.
